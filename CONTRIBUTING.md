# Contributing

Contributions are welcome and encouraged! To contribute:

1. Review the [license](UNLICENSE) and confirm you're OK with it.
2. Fork the repo
3. Copy / paste your CHIRP setup into one of the existing files, or create a
   new file. Note we're trying to organize things a bit, with preferred club
   repeaters in one file, interesting non-Ham frequencies in another, etc.
   Please try to follow the organizational pattern.
4. Commit your changes. Please include a good commit message detailing what
   new frequencies you added, where, and whether you've created any new
   categories.
5. [Create a PR](https://github.com/dongola7/n2ycr_chirp/compare) to get your changes reviewed and approved!
